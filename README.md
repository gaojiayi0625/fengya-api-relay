# fengya-api-relay

蜂芽 AI API 中转站是一个面向多模型聚合场景的统一 API 网关平台。根据项目现有介绍，平台接入 7 家厂商、16+ 模型，提供 OpenAI、Claude、Gemini 协议兼容，并支持支付宝在线充值、用量监控与令牌管理。

## 项目能力

- 多厂商、多模型统一接入
- OpenAI / Claude / Gemini 协议兼容
- 用量监控与令牌管理
- 支付宝在线充值

## 安全提示

- 不要在 Issue、日志、截图或提交记录中公开 API 密钥、访问令牌和支付凭据。
- 建议为令牌设置最小权限、额度上限和失效时间，并定期轮换。
- 在生产环境接入前，请核对上游厂商的数据处理与隐私政策。
- 日志与监控信息应对密钥、手机号、订单号等敏感字段进行脱敏。
